# Retrieval Task Scripts Documentation

This repository contains scripts for running retrieval tasks using various baseline and proposed models.  
Before running any of the scripts, please refer to the **`argparse`** options inside each file to familiarize yourself with the available command-line arguments.

---

## 🧩 `baselines_retrieval.py`

**Description:**  
Runs inference for baseline models (`CLIP`, `CLIP-NegFull`, `ConCLIP`, `NegCLIP`, `NegCLIP-NegFull`) on the retrieval task.

**Example Usage:**
```bash
python Retrieval/baselines_retrieval.py \
    --dataset coco \
    --pretrained_model clip \
    --clip_backbone ViT-B/32 \
    --neg_retrieval
```

---

## 🚀 `space_idea_retrieval_LLM_simplified.py`

**Description:**  
Runs inference for our proposed method on the retrieval task using **split captions** generated by the fine-tuned LLM.  
This version is optimized for simplicity and faster validation experiments.

**Example Usage:**
```bash
python Retrieval/space_idea_retrieval_LLM_simplified.py \
    --dataset coco \
    --threshold 0.92 \
    --pretrained_model clip \
    --clip_backbone ViT-B/32
```

> 💡 **Note:** The `--threshold` value (default `0.92`) should be cross-validated for optimal performance.

---

## 🧠 `space_idea_retrieval_LLM.py`

**Description:**  
Runs inference for our proposed method on the retrieval task using the **fine-tuned LLM** as a caption processor in sequence with the CLIP model.  
While this script provides more flexibility, the simplified version (`space_idea_retrieval_LLM_simplified.py`) is recommended for quicker experiments.

**Example Usage:**
```bash
python Retrieval/space_idea_retrieval_LLM.py \
    --dataset coco \
    --threshold 0.92 \
    --pretrained_model clip \
    --clip_backbone ViT-B/32 \
    --llm_finetuned_path mistral-7B-sft-Negation/checkpoint-426
```
> 💡 **Note:** The `--threshold` value (default `0.92`) should be cross-validated for optimal performance.
